# Конфигуриране на възел

Конфигурацията на възела варира между различните реализации.

- За Kubo вижте [config.md](https://github.com/ipfs/kubo/blob/master/docs/config.md).
- За Helia вижте документацията [HeliaInit](https://ipfs.github.io/helia/interfaces/helia.HeliaInit.html). Имайте предвид, че за разлика от остарялата js-ipfs реализация, трябва да конфигурирате възела директно — вижте [Helia example](https://github.com/ipfs/helia/wiki/Migrating-from-js-IPFS#config).
