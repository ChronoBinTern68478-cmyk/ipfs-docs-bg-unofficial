# Инсталирайте IPFS Kubo

Това ръководство описва наличните процеси на инсталиране за IPFS Kubo, Go-базирана имплементация на протокола InterPlanetary File System (IPFS). Kubo беше първата имплементация на IPFS и е най-широко използваната имплементация днес. Kubo ви позволява да правите всичко, което IPFS Desktop може, но на по-гранулирано ниво, защото можете да посочите кои команди да изпълнявате. Kubo има следните функции:

  • Стартира IPFS-нода като мрежова услуга, която е част от LAN и WAN (Amino (opens new window)) DHT
  • Функционалност на HTTP Gateway (opens new window) (/ipfs и /ipns) за доверено и trustless (opens new window) извличане на съдържание
  • Клиент и сървърна имплементация на HTTP Routing V1 (opens new window) (/routing/v1) за търсене чрез delegated routing (opens new window)
  • HTTP Kubo RPC API (opens new window) (/api/v0) за достъп и управление на демона
  • Command Line Interface (opens new window) (ipfs --help), базиран на RPC API (/api/v0)
  • WebUI (opens new window) за управление на Kubo нода
  • Поддръжка на Content blocking (opens new window) за оператори на публични възли
  • Бинарни файлове за Windows, macOS, Linux, FreeBSD и OpenBSD

Инсталирането на Kubo през командния ред е полезно за много сценарии, като например създаване на приложения и услуги върху IPFS нода или настройване на възел без потребителски интерфейс (както обикновено е при отдалечени сървъри или виртуални машини).

За да започнете, запознайте се с системните изисквания. След това решете дали искате да инсталирате Kubo с един от 5-те официални бинарни дистрибуции или да съберете Kubo от източник. След като инсталирате Kubo, определете кой възел да използвате в командния ред. Накрая разгледайте следващите стъпки.

WARNING

Събирането от източник се препоръчва само ако стартирате Kubo на система с тежки ограничения на ресурсите или допринасяте за проекта Kubo.

# Системни изисквания

Kubo работи на повечето Windows, macOS, Linux, FreeBSD и OpenBSD системи, които отговарят на следните изисквания:

  • 6 GiB RAM.
  • 2 CPU ядра (kubo е силно паралелен).

Имайте предвид следното:

  • Количеството дисково пространство, което вашата IPFS инсталация използва, зависи от това колко данни споделяте. Базовата инсталация използва около 12 MB дисково пространство.
  • Можете да активирате автоматично почистване на отпадъци чрез --enable-gc и да регулирате по подразбиране максималното дисково съхранение (opens new window) за данни, извлечени от други peers.

# Инсталиране на официални бинарни дистрибуции

Този раздел описва как да изтеглите и инсталирате Kubo бинарния файл от dist.ipfs.tech на Windows, macOS, Linux, FreeBSD и OpenBSD операционни системи. Екипът на IPFS публикува най-новите официални предварително компилирани Kubo бинарни файлове на уебсайта dist.ipfs.tech (opens new window). Новите версии на IPFS Kubo бинарните файлове автоматично се показват на страницата Kubo в dist.ipfs.tech.

Ако нямате достъп до dist.ipfs.tech (opens new window), можете също да изтеглите Kubo от GitHub releases (opens new window) страницата на проекта или от /ipns/dist.ipfs.tech през dweb.link (opens new window) gateway.

За инструкции за инсталиране за вашата операционна система изберете подходящия раздел.

::: tab Linux id="install-kubo-linux"

# Linux

  1. Изтеглете Linux бинарния файл от dist.ipfs.tech (opens new window).

    wget https://dist.ipfs.tech/kubo/v0.43.1/kubo_v0.43.1_linux-amd64.tar.gz

  2. Разархивирайте файла:

    tar -xvzf kubo_v0.43.1_linux-amd64.tar.gz

> x kubo/install.sh
> x kubo/ipfs
> x kubo/LICENSE
> x kubo/LICENSE-APACHE
> x kubo/LICENSE-MIT
> x kubo/README.md

  3. Преминете в папката kubo:

    cd kubo

  4. Стартирайте инсталационния скрипт

    sudo bash install.sh

> Moved ./ipfs to /usr/local/bin

  5. Проверете дали Kubo е инсталиран правилно:

    ipfs --version

> ipfs version 0.43.1

::: tab Windows id="install-kubo-windows"

# Windows

  1. Изтеглете Windows бинарния файл от dist.ipfs.tech (opens new window).

    wget https://dist.ipfs.tech/kubo/v0.43.1/kubo_v0.43.1_windows-amd64.zip -Outfile kubo_v0.43.1.zip

  2. Разархивирайте файла на подходящо място, например ~\Apps\kubo_v0.43.1.

    Expand-Archive -Path kubo_v0.43.1.zip -DestinationPath ~\Apps\kubo_v0.43.1

  3. Преминете в папката kubo_v0.43.1

    cd ~\Apps\kubo_v0.43.1\kubo

  4. Проверете дали ipfs.exe работи:

    .\ipfs.exe --version

> ipfs version 0.43.1

    В този момент Kubo е използваем. Въпреки това силно се препоръчва първо да добавите ipfs.exe към вашия PATH, като следвате следните стъпки:

  5. Запазете текущата работна директория в временна променлива:

    $GO_IPFS_LOCATION = pwd

  6. Създайте PowerShell профил:

    if (!(Test-Path -Path $PROFILE)) { New-Item -ItemType File -Path $PROFILE -Force }

    Тази команда първо проверява дали имате зададен профил. Ако имате, тя го оставя и не създава нов. Можете да прегледате съдържанието на профила си, като го отворите в редактор, като Notepad:

    notepad $PROFILE

  7. Добавете местоположението на вашия Kubo демон и го добавете към PATH на PowerShell, като го добавите в края на вашия PowerShell профил:

    Add-Content $PROFILE "`n[System.Environment]::SetEnvironmentVariable('PATH',`$Env:PATH+';;$GO_IPFS_LOCATION')"

  8. Заредете вашия $PROFILE:

    & $profile

  9. Отидете в домашната си папка

    cd ~

  10. Проверете дали Kubo е инсталиран правилно:

    ipfs --version

> ipfs version 0.43.1

# macOS

Методът за инсталиране с brew поддържа както Intel, така и Apple Silicon хардуер. Ако предпочитате ръчна инсталация, артефактите darwin-amd64 (Intel) и darwin-arm64 (Apple Silicon) са налични тук (opens new window).

  1. Отворете терминал.

  2. Използвайте brew, за да инсталирате Kubo:

    brew install ipfs

  3. Потвърдете инсталацията на Kubo:

    ipfs --version

    Ако Kubo е инсталиран, се показва номерът на версията. Например:

    > ipfs version 0.43.1

# Компилиране на Kubo от източник

За актуални инструкции как ръчно да изтеглите, компилирате и съберете Kubo от източник, вижте раздела Събиране от източник (opens new window) в хранилището на Kubo.

# Определяне кой възел да използвате с командния ред

CLI автоматично се свързва с работещ IPFS демон, като прочита файла $IPFS_PATH/api (обикновено ~/.ipfs/api), който съдържа адреса на RPC API.

  • Локален демон: Изпълнението на ipfs daemon създава този файл автоматично.
  • Отдалечен възел: За свързване към демон на друга машина или в контейнер, вижте Свързване с отдалечен възел.

TIP

За API със TLS защита, вижте Защитен Kubo RPC с TLS и HTTP Auth. Ако се интересувате само от извличане, вместо това вижте HTTP Gateway, който е независим от имплементацията.
